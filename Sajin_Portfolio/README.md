## Getting Started

### Prerequisites

- Node.js and npm
- Git

### Clone the Repository

```bash
git clone https://github.com/sajin-cl/sajin-cl-developer-portfolio.git
```

### Navigate to the Project

```bash
cd sajin-cl-developer-portfolio
```

### Install Dependencies

```bash
npm install
```

### Run Locally

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

> These commands assume the project uses npm and defines the corresponding scripts in `package.json`.

## Contact Form
